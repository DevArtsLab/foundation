Decisions, contracts, and procedures governing every repository produced
from this workspace. Platform and brand are recorded as decisions here,
not assumed.

Documentation only: no code, templates, or configuration.

## Layout

See [INDEX.md](INDEX.md).

- `concepts/` - why the system is shaped this way
- `reference/` - contracts, catalogs, limits, registers, policies
- `guides/` - procedures (project start, predevelopment, ADR template)
